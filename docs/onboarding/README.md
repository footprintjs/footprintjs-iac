# Onboarding source map

Generated by `npm run context:onboarding`; freshness check: `npm run context:onboarding:check`.

This is a source navigation map. Actual execution, selected paths, outcomes and backwalk require retained native recordings. Read source freely when this inventory is insufficient.

Discover system → Configure connection → Verify connections → Review changes → Deploy and test. Human actions separate these stages. One native chart records each admitted action; this map does not claim they execute automatically or in parallel.
